## 👨‍💻 About me

**Ishan Builds** — I help solo creators, consultants, and small businesses cut out repetitive manual work with AI agents, automations, and full-stack systems, sized to what you need.

I'm an engineer first: I build the whole chain, keep it fast and simple, and write real code when no-code runs out of road.

## 🚀 Projects

### 🎙️ SYM — personal AI assistant
Runs errands: checks mail, writes docs, pulls GitHub stats, plans things. An LLM planner generates a DAG of tasks and an executor runs them as background jobs with Celery. MVP targets realtime voice with barge-in.

Checks GitHub for new code changes and fetches them with one `koushin upgrade` command, for people who find pip/uv difficult.
