## Projects

**🎙️ SYM: personal AI assistant**
Runs errands like checking mail, writing docs, pulling GitHub stats, and planning things. An LLM planner generates a DAG of tasks and an executor runs them as background jobs. MVP targets realtime voice with barge-in.
`Python` `React` `Celery` `WebSockets`

**🔄 koushin: a simple updater for Python packages**
Checks GitHub for new code changes and fetches them with one `koushin upgrade` command, for people who find pip/uv difficult.
`Python` `asyncio`

**🧩 n8n workflows**
Automation workflows with written case studies, built to do complex things simply.
`n8n`
