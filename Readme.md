## 🚀 Projects

### 🎙️ SYM — personal AI assistant
Runs errands: checks mail, writes docs, pulls GitHub stats, plans things. An LLM planner generates a DAG of tasks and an executor runs them as background jobs with Celery. MVP targets realtime voice with barge-in.
